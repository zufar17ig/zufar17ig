## Featured project — Rakiya

**A hyperlocal short-term work marketplace, starting with a Gampaha pilot concept.**

Rakiya connects the worker and employer journeys: discover nearby opportunities, apply, share contact details after acceptance, and record work and compensation confirmations from both sides.

## What I'm working on

- **Product:** turning a local labour-market problem into a clear worker/employer experience.
- **Design:** accessible, mobile-first flows with English and Tamil interface text.
- **Development:** a Django marketplace backend, a responsive web client, and shared React Native mobile source.
- **Validation:** reproducible tests, documented limitations, and preparation for real pilot feedback.

I use **AI-assisted development** to turn product ideas into working prototypes, with a focus on understanding, testing and improving what gets built.
